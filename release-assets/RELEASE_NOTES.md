## Counterfire 2.6.0

This release introduces the redesigned Counterfire interface and secure
automatic updates.

Highlights:

- Manual bearing triangulation and artillery marker tracking
- Russian and United States artillery identification with unit icons
- Firing cadence matching, reload countdowns, and time-since-fired markers
- Marker relocation history and configurable reminders
- Online minimaps, map orientation controls, and multi-monitor layouts
- Scalable control panel and overlay content
- Numpad-focused controls with configurable hotkeys
- HTTPS update checks with installer size and SHA-256 verification

Counterfire remains an external manual-input tool. It does not access Broken
Arrow files, process memory, network traffic, or screen pixels.
