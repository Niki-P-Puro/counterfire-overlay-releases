# Counterfire Releases

Official Windows releases for Counterfire, an external manual artillery
coordination overlay for Broken Arrow.

Counterfire does not read or modify Broken Arrow files, process memory, network
traffic, or screen pixels. Download the current installer from the repository's
Releases page.

The application checks this repository's latest release for updates. Downloads
are accepted only over HTTPS and must match the byte size and SHA-256 hash in
the published update manifest before the installer can run.
