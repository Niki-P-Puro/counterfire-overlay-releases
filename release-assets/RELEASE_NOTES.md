## Counterfire 3.2.6

Adds four selectable map modes: 4096-pixel Detailed Satellite, Tactical Minimap, Cartographic, and Classic. Detailed maps download lazily per selected map, cache locally, and use strict HTTPS host, size, format, and image validation. Counterfire never modifies game files.

Counterfire is an external manual-input tool. It does not access Broken Arrow
files, process memory, network traffic, or screen pixels.
